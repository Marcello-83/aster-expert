# Consignes et comptes rendus des lots

Depuis le lot 41 ter, les consignes de MM et les comptes rendus de lot peuvent
vivre ici, versionnés avec la branche du lot (`lot-NN`), plutôt que dans le
dossier partagé `/media/sf_partage` (qui n'existe que dans la VM et reste la zone
d'échange des livrables lourds).

Conventions :

- `lotNN_consigne.md` : la consigne du lot, recopiée telle que MM l'a donnée ;
- le compte rendu complet reste le message du commit du lot (CLAUDE.md, « Fin de
  lot ») ; un rapport d'essai reste `docs/essais_lotNN.md` ;
- rien de ce qu'interdit `docs/publication_github.md` (secrets, fichiers de MM,
  texte de norme, fichiers de plus de 50 Mo) n'est déposé ici.
